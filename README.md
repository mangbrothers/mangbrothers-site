# mangbrothers-site

This is the public website for Mangiapane Brothers Lawn & Snow LLC, at https://mangbrothers.com. It is built with Astro and hosted on GitHub Pages.

## Editing and deploying
1. Run `npm install` once, then `npm run dev` to preview the site at http://localhost:4321.
2. Make your edits. Content lives in `src/`, and prices are in `src/data/services.ts`.
3. Run `npm run build` to confirm the build passes.
4. Commit and push to `main`. The GitHub Action builds the site and deploys it in about a minute.

Do not upload files through the GitHub website.

Design sources are in `design/`, and the working rules are in `CLAUDE.md`.
